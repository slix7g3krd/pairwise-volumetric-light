# pairwise-volumetric-light

探照灯扫过仓库时，光柱在柱子后面断成两截，粒子一多又整片糊掉：体积光按固定世界步长采样，光源远近和阴影级联分辨率不匹配；半分辨率缓冲用空间降噪，移动光源下噪点被拉成条；透明粒子只写颜色不写深度，光柱穿过烟雾时没有衰减；相位函数固定各向同性，侧逆光和前向散射强度一样；阴影贴图深度不连续处没有提前终止，背景被前景光污染；动态光源每帧重建光锥，旧光源的历史权重还在累积；点光源和聚光灯共用一套步进参数，点光源边缘过亮；色调映射在体积光之前执行，HDR 光柱被压成灰；异步 compute 和主渲染队列竞争，光柱晚一帧；分辨率切换后光锥纹理没重建，边缘出现黑框；多视图渲染共用一张体积光图，VR 左右眼串图；采样数按固定值，近景过采样远景不足；透明物体排序和体积光步进顺序冲突，重叠区重复积分。render/volumetric_light.py 是核心，tests/test_volumetric_light.py 15个红。要修的是：级联自适应步长；时空降噪；透明深度衰减；相位函数；深度提前终止；动态历史清理；光源类型分离；色调映射顺序；异步同步；分辨率重建；多视图隔离；采样数自适应；透明排序。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
